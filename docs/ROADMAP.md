# Roadmap

The first public release concentrates on widescreen composition, borderless display, MSAA and configurable keyboard bindings.

Next visual work: qualify a wider map with coherent geography, labels, dynamic markers and mouse picking; test every town/interior variant and activity; expand device-loss and GPU coverage.

High-FPS work remains research. The native simulation and animation timing must stay unchanged. The rigid-hull investigation has a guarded native control and an observed default rendering program, but owned-transform consumption has not been proven. Nested texture-resource lookup and operation-local resource eligibility remain to be qualified. Interpolation, extra frames and sustained history are not part of the public release.

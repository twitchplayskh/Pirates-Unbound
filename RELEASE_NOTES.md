# Pirates! Unbound v0.1.0-beta.1

First public beta for the inspected Steam 1.0.2.0 version of Sid Meier's Pirates! (2004), on Windows.

Download **Pirates-Unbound-v0.1.0-beta.1-Windows.zip**. Extract its PiratesWide folder beside Pirates!.exe, then set Steam's Launch Options to the quoted PiratesWideLauncher.exe path followed by `%command%`. Installation and removal instructions are in README.md.

Includes widescreen world rendering, centered clickable UI, borderless fullscreen, resolution settings up to 4K, MSAA and a keyboard remapping editor. Town scenery, dialogue fades and tavern scene-copy layers have composition fixes. This release adds the missing national flag variants so they follow their town scenery and flagpoles.

**High-FPS/interpolation research is disabled. Original gameplay timing is preserved.** The map retains its proportional 4:3 geography with parchment margins; wider map rendering requires further work. Not every town, interior, game mode, GPU or extended session has been validated. Other game editions and wrapper combinations are untested.

Existing installs: quit the game/launcher and replace the included program files, keeping settings.xml and backups. No game executable, artwork, archives, settings or saves are distributed. See SHA256SUMS.txt to verify the download.

Please report scene-specific visual bugs with town, resolution, launcher options and reproduction steps. This is an independent community project, not an official Firaxis/2K patch.
